## 출처와 이용조건

혼잡도 3개 파일의 제공기관은 서울교통공사이며 서울 열린데이터광장에서 받았습니다.

- 자료명: 서울교통공사 지하철혼잡도정보
- 출처: https://data.seoul.go.kr/dataList/OA-12928/A/1/datasetView.do
- 기준일 표기: 2025-11-30, 2026-03-31, 2026-06-30
- 포털 표시 이용조건: 공공누리 제3유형(출처표시 + 변경금지).
- 원본을 변경 없이 보관·배포합니다. 가공 데이터나 파생 결과의 공개 가능 범위는 별도로 확인해야 합니다. 코드에 적용되는 조건이 데이터 이용조건을 대체하지 않습니다.

시간표의 제공기관은 서울교통공사이며 공공데이터포털에서 받았습니다.

- 자료명: 서울교통공사 서울 도시철도 열차운행시각표, 2026-06-16
- 출처: https://www.data.go.kr/data/15098251/fileData.do
- 포털 표시 이용조건: 이용허락범위 제한 없음.
- 계획 운행시각이며 실제 지연 기록이 아닙니다. 24시·25시는 익일 시각입니다.

## 사용 시 확인할 점

- CSV는 CP949입니다. 엑셀 파일은 평일·토요일·일요일 시트를 각각 읽습니다.
- 2025 CSV는 `요일구분`, `출발역`, `5시30분` 형태이고 2026 XLSX는 `구분`, `역명`, `05:30~06:00` 형태입니다. 결합 전에 열 이름과 자정 이후 시각을 정규화해야 합니다.
- 혼잡도는 역·방향·요일유형·30분 집계 평균이며 개별 열차·객차의 관측값이 아닙니다.
- 서로 다른 기준기간의 혼잡도와 2026년 시간표를 결합하는 경우 기간 불일치를 기록해야 합니다.
- 이번 작업은 원본 수집·구조·구간 포함 확인까지입니다. 정차 연결·방향 정규화·시간표와 평균 조인은 아직 하지 않았으므로 `processed/`는 비어 있습니다.

## 재수집

전역 Python에서 실행합니다. 추가 패키지나 가상환경은 필요하지 않습니다.

```powershell
python -m subway.collect_data
```

기록된 파일은 해시를 검증하고 건너뜁니다. 기존 파일을 덮어쓰지 않습니다. 다운로드 주소가 바뀌면 출처 페이지에서 새 주소를 확인해야 합니다.
